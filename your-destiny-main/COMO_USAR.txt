 YOUR DESTINY v2 — COMO USARLO Y EJECUTARLO EN OTRO EQUIPO
=====================================================================

QUE ES
------
Sitio web de una agencia ficticia de buses de Colombia.
Backend: Python (Flask) + MySQL 8. Todo corre en Docker.

---------------------------------------------------------------------
REQUISITO UNICO EN EL OTRO EQUIPO
---------------------------------------------------------------------
Tener instalado Docker Desktop (Windows/Mac) o Docker Engine +
Docker Compose (Linux). Descarga: https://www.docker.com/get-started

No hace falta instalar Python, ni MySQL, ni nada mas.

---------------------------------------------------------------------
PASOS PARA EJECUTARLO EN OTRO EQUIPO
---------------------------------------------------------------------
1. Copiar la carpeta completa del proyecto "your_destiny" al otro
   equipo (por USB, red, git, zip, etc.). Basta con estos archivos:

     app.py
     requirements.txt
     Dockerfile
     docker-compose.yml
     .dockerignore
     static/            (carpeta completa: html, css, js, img)

   Los archivos README.md, YOUR_DESTINY_V2.md y este .txt son solo
   documentacion; no son necesarios para correr la app.

2. Abrir una terminal (PowerShell, CMD o bash) DENTRO de la carpeta
   del proyecto.

3. Ejecutar:

     docker compose up -d --build

   La primera vez tarda unos minutos porque descarga las imagenes de
   Python y MySQL. Las siguientes veces arranca en segundos.

4. Esperar unos 20-30 segundos a que MySQL termine de iniciar
   (la app reintenta la conexion sola) y abrir en el navegador:

     http://localhost:5000

LISTO. La base de datos, las tablas y los datos de ejemplo se crean
automaticamente la primera vez.

---------------------------------------------------------------------
COMO USARLO
---------------------------------------------------------------------
- Pagina principal (http://localhost:5000):
  boton "Iniciar sesion" para entrar como administrador.
    Usuario: admin     Contrasena: 1234

- "Cotizar viaje" (/cuendesti.html):
  formulario que guarda la cotizacion en la base de datos y muestra
  un resumen con el numero de solicitud.

- "Combos" (/comysug.html):
  al pulsar "Seleccionar" en un combo, se guarda la eleccion y se
  abre el formulario de cotizacion con el combo aplicado.

- "Destinos" (/destacados.html):
  galeria de 6 destinos cargada desde la base de datos.

- Panel de administracion (/admin.html):
  solo accesible tras iniciar sesion como admin. Tiene 4 pestanas:
    * Cotizaciones: lista todas y permite cambiar su estado
      (pendiente / confirmada / cancelada) desde el desplegable.
    * Usuarios: crear usuarios (rol cliente o admin) y eliminarlos.
      No se puede eliminar el propio usuario con el que se entro.
    * Combos: crear, editar y eliminar combos (nombre, detalle, precio).
      Para editar, pulsar "Editar", modificar y "Guardar cambios".
    * Destinos: crear, editar y eliminar destinos de la galeria.
      El campo "Imagen" debe ser el nombre de un archivo existente
      en static/img (ej. cartagena.jpg).

---------------------------------------------------------------------
COMANDOS UTILES
---------------------------------------------------------------------
Ver el estado de los contenedores:
  docker compose ps

Ver los logs de la aplicacion:
  docker compose logs -f app

Detener todo (los datos se conservan):
  docker compose down

Detener todo y BORRAR la base de datos (reinicio desde cero):
  docker compose down -v

Volver a levantar despues de detener:
  docker compose up -d

Entrar a la base de datos MySQL directamente:
  docker compose exec db mysql -uroot -proot123 your_destiny
  (ejemplo de consulta:  SELECT * FROM cotizaciones;)

Limpiar las cotizaciones de prueba (sin tocar destinos ni combos):
  docker compose exec db mysql -uroot -proot123 your_destiny -e "DELETE FROM cotizaciones;"
  NOTA: la base de datos incluye 2 cotizaciones de ejemplo (ids 1 y 2)
  para poder ver el panel admin funcionando. Si prefieres entregarla
  vacia, usa el comando anterior.

---------------------------------------------------------------------
SOLUCION DE PROBLEMAS
---------------------------------------------------------------------
- "docker no se reconoce como comando": abrir Docker Desktop y
  esperar a que termine de arrancar (icono de la ballena estable).
- "port 5000 is already allocated": otro programa usa el puerto 5000.
  Editar docker-compose.yml y cambiar "5000:5000" por "8080:5000";
  luego abrir http://localhost:8080
- La pagina no carga datos al primer arranque: esperar unos segundos
  mas y recargar (MySQL tarda en inicializarse la primera vez).
